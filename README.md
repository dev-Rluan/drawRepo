# drawRepo

서비스 흐름과 학습 내용을 정리한 다이어그램 원본을 보관합니다.

## 파일 안내

| 파일 | 내용 |
|---|---|
| [purpleDialy-logic.drawio](purpleDialy-logic.drawio) | 일기 프로젝트의 로직 다이어그램 |
| [spring-security.drawio](spring-security.drawio) | Spring Security 학습 다이어그램 |
| [제목 없는 다이어그램.drawio](<제목 없는 다이어그램.drawio>) | 제목을 정리하지 않은 다이어그램 |
| [pupleDialy](pupleDialy) | 확장자 없이 보관한 관련 자료 |

`.drawio` 파일을 내려받아 diagrams.net(draw.io)의 파일 열기로 확인하고 편집할 수 있습니다. 그림을 보는 목적과 서비스 실행 방법은 구분합니다.
